# Exanite.Slang

Requirements:
- This will be a C library, or at least a library compatible with Silk.NET's SilkTouch generators.
- This will be compiled as a shared library.
- The headers of this library will be used to generate C# bindings with Silk.NET's SilkTouch.
- The Slang library itself will be unmodified and included as a separate shared library.
- This means that this library will need to load the Slang library.
